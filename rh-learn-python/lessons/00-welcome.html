agent 是什么

聊天机器人只会聊天。这台机器人是 agent：它还能在你的电脑上读文件、改代码、跑命令。下面是一次真实的对话：

agent 不光会说，还会用工具动手做事。

大脑 + 身体

AI 模型像一颗泡在罐子里的大脑：只会读进文字、写出文字，没有手，也没有记忆。其余的事都归 harness 管，也就是你要拆开的这个 Python 程序：

  • 心跳（循环）：问你，问 AI，跑工具，再来一遍。
  • 双手（工具）：读文件、列文件夹、改代码、跑命令的小函数。
  • 记忆（对话记录）：一个列表，记下说过的每一句话。
  • 规矩（系统提示词）：比如「改文件前先读一遍」。

没有 harness，AI 模型自己能做什么？

  1. 打开并读取你电脑上的文件
  2. 读进文字，写出文字，仅此而已
  3. 在你的终端里运行命令
  4. 记住你说过的所有话

模型就是「文字进、文字出」。读文件、跑命令、记住上文，全是外面那个 Python 程序在做。

Agent = 模型 + harness。这门课拆的是 harness。

注释

Python 从上到下一行一行执行。# 后面的内容是注释，Python 会跳过它，它是写给人看的。

这个程序会打印出什么？

  1. 1、2、3、4
  2. 1 和 4
  3. 1、2 和 4
  4. 4、2、1

第 3 行是注释，不会执行；第 2 行末尾的注释只藏起 # 后面的字。这样「注释掉」一行，就能暂时关掉它。

编程原则

注释写「为什么」

# 给 x 加 1 这种注释没用，代码已经说了。好注释讲代码讲不出的东西：为什么这样写，不这样会出什么事。

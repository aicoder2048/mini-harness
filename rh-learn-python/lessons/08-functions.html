函数

函数是有名字的小机器：放进值，交回结果。机器人的每个工具都是一个函数。

写个函数

print()、len() 都是函数。用 def 可以自己写一个：定义时不运行，调用时才运行；return 把结果交回来。

这个程序会打印什么？

  1. 5
  2. None
  3. a + b
  4. 报错

算出来了，但没有 return，结果就丢了。没有 return 的函数交回 None。修好它：return a + b。

多了解一点：print 和 return 不一样

print 把值显示给人看，然后就扔了；return 把值交回给代码，能存起来接着用。

def 定义，调用才运行；没有 return 就交回 None。

参数和默认值

参数是函数的「空位」。带 = 默认值的参数调用时可以不填；写上参数名（关键字参数），顺序就随意。

多了解一点：几个常见错误
  • 先调用、后定义：Python 从上往下读，def 要写在第一次调用之前。
  • 局部变量：函数里创建的变量，函数一结束就没了。外面要用，就 return 它。
  • 拿列表当默认值：默认值只创建一次，所有调用共用。用 None，再在函数里新建列表。

带默认值的参数可以不填，不带的必须给。

编程原则

一个函数只干一件事，别重复自己

一句话说不清函数干什么，就拆开。同样的代码出现两次，就写成函数（DRY：Don't Repeat Yourself）。

共用的代码只写一次，改一处，全修好。

纯函数

纯函数：同样的输入永远得到同样的输出，而且不碰外面的世界（不打印、不读写文件、不问用户）。它最好测试。

下面哪个函数是纯函数？

  1. 返回 input("Allow? ") 的函数
  2. 把一条笔记存进文件的函数
  3. 返回 ALL_TOOLS[: step - 1] 的函数
  4. 返回今天日期的函数

它每次都给出同一个列表，也不碰外面。测试只要一行：assert tools_for_step(3) == ["read_file", "list_files"]。

同样输入、同样输出、不碰外面：纯函数最好测。

函数也是值

函数可以像数字一样存进变量和字典。定义工具时写的是 run=_run_bash（tools.py 第 264 行），没有括号：存下函数本身，要用时再调用。

为什么写 run=_run_bash，而不是 run=_run_bash()？

  1. 这是个碰巧能用的笔误
  2. 这样存下的是函数本身，等 AI 要用时机器人再去调用它
  3. 名字以 _ 开头的函数不需要圆括号
  4. Python 会自动补上圆括号

加了括号，机器人一启动就会运行它（还没有命令可跑）。不加括号，函数被存起来，到时候由 tool.run(...) 调用。

不加括号是函数本身，加了括号才是调用。

动手挑战

挑战

安全的行数上限

写 safe_limit(value, maximum=500)：value 不是 int 或小于 1，就返回 maximum；否则返回两者中较小的那个。

例：safe_limit(10) → 10，safe_limit(9999) → 500，safe_limit("20") → 500。

提示

先处理不合格的情况，尽早 return maximum；min(a, b) 取较小值。

挑战

长输出只留结尾

写 truncate_tail(text, limit)：不超过 limit 就原样返回；否则返回一行英文说明、换行，再加最后 limit 个字符，像这样：

... (truncated: showing last 18 of 32 chars)
ERROR: test failed
提示

text[-limit:] 是最后 limit 个字符；说明那行用 f-字符串和 len(text) 拼。

小结

  • def 定义函数，调用时才运行；return 交回结果，没有就是 None。
  • 默认值让参数可选；关键字参数可以不按顺序。
  • 一个函数一件事；纯函数最好测试。
  • 函数也是值：run=_run_bash 存起来，tool.run(...) 再调用。

self 与状态

不用 @dataclass 时，自己写 __init__：每造一个对象，它就自动运行一次。类里的函数叫方法，第一个参数 self 就是「这一个对象」：

ConsoleApprover 里运行 self.always.add(call.name) 时，self 是什么？

  1. 类 ConsoleApprover 本身
  2. 此刻正在被询问的那一个授权对象
  3. 正在等待授权的那次工具调用
  4. 一个全局变量

每个 Agent 都有自己的授权对象，所以在一个会话里回答 a，不会影响另一个会话。

会变的数据放在 self 上，每个对象各有一份。

编程原则

依赖插头，不依赖设备

照着零件「能做什么」来写代码，再从外面把零件传进来（Agent(provider, ...)）。这样测试时每个零件都能换成假的。

小结

  • 类是蓝图，对象是造出来的东西：Tool(...)。
  • @dataclass 按字段造类；frozen=True 造好就不能改。
  • __init__ 设置新对象；self 就是「这个对象」。
  • 方法对得上的零件都能插进来，所以测试能用假大脑。

字符串与输入

字符串就是引号里的文字，单引号、双引号都行。+ 把它们拼起来，len() 数有几个字符。

input() 先显示一句提示，再等用户打一行字。它给你的永远是字符串，哪怕打的是数字。

print("5" + "5") 会显示什么？

  1. 10
  2. 55
  3. TypeError 报错
  4. 5 5

字符串之间的 + 是拼接："5" 加 "5" 得到 "55"。而 "5" + 5 会报 TypeError。

input() 给的是文字；要做算术，先用 int() 转换。

f-字符串

用 + 拼多了很乱。在引号前加个 f，再把变量写进 { }，Python 会帮你填空。{x:,} 还能给大数字加千位分隔符。

你忘了写 f。这段代码会打印什么？

  1. 你好 小闪
  2. 你好 {name}
  3. 报错
  4. 你好 name

没有 f，花括号就是普通字符。忘写 f 不会报错，所以特别容易漏掉。

f"...{变量}..."：花括号里的东西会被填进去。

终端上色

反斜杠开头的是转义字符：\n 是换行，\033 是一个看不见的 ESC 字符。终端看到 \033[94m 就把后面的字变成亮蓝色，看到 \033[0m 就恢复正常。

代码颜色机器人用来
\033[94m亮蓝You:
\033[93m亮黄DeepSeek:
\033[92m亮绿tool:
\033[91m亮红→ error
\033[0m恢复每个彩色词后面

试试删掉一个 {RESET}，看颜色怎样「漏」到后面去。

颜色代码开头，\033[0m 收尾。

字符串方法

每个字符串都自带一些工具，叫方法，用点来调用。最常用的几个：

方法例子
.strip() 去掉两头空白" hi \n".strip() → "hi"
.lower() 变小写"YeS".lower() → "yes"
.split() 拆成词"/exit now".split() → ['/exit', 'now']
.replace(a, b) 替换"x = 1".replace("1", "2") → "x = 2"

方法不改原字符串，而是返回一个新的。

切片

每个字符都有位置编号，从 0 开始；-1 是最后一个。text[a:b] 取从 a 到 b 之前的一段，省略一头就取到底。

编程原则

不要悄悄剪掉内容

缩短了东西就说出来。机器人的注释原话：「悄悄截断比不截断更糟」。

"read_file"[:4] 是什么？

  1. "read"
  2. "read_"
  3. "file"
  4. "r"

位置 0–3 是 r、e、a、d，在 4 之前停下。[:4] 就是「前 4 个」。

[:n] 取开头 n 个，[-n:] 取结尾 n 个。

小结

  • input() 永远返回字符串，算术前先 int()。
  • f-字符串用 { } 填空；\033[94m … \033[0m 给文字上色。
  • .strip()、.lower() 等方法返回新字符串。
  • 切片 [:n]、[-n:] 取开头或结尾；剪了就要说。

关键词

字符串 string
引号里的文字。
f-字符串 f-string
带 f、能填空的字符串。
转义字符 escape sequence
像 \n 的反斜杠代码。
方法 method
用点调用的工具，如 .strip()。
索引 index
字符的位置，从 0 开始。
切片 slice
字符串的一段：text[a:b]。

挨个过一遍

for 循环读作：对列表里的每个元素，运行一次缩进的代码。每转一圈，Python 把下一个元素放进变量 tool，过完就停。

手里有一组东西要挨个处理，就用 for。

数字和编号

range(n) 给出 0 到 n-1 的数字；enumerate() 把每个元素和它的编号一起给你。

这段代码会打印什么？

  1. 2 3 4 5
  2. 2 3 4
  3. 0 1 2 3 4
  4. 3 4 5

range(2, 5) 从 2 开始，在 5 之前停下。少算或多算一次，是最常见的 bug 之一。

range(a, b) 包括 a，不包括 b。

循环套循环

list_files 要走遍每个文件夹，再看遍文件夹里的每个文件：循环里套着循环。

外层每转一圈，内层都要从头跑完一遍。

推导式

用循环拼新列表太常见了，Python 给了一行的简写：[要留下的 for 元素 in 列表 if 条件]。上面第 120 行就是一个。

result 里是什么？

  1. [2, 4, 6]
  2. [2, 6]
  3. [1, 3]
  4. [4]

从中间读起：对每个 n，如果 n != 2，就留下 n * 2。也就是 1 × 2 和 3 × 2。

多了解一点：别一边遍历一边改同一个列表

在 for 里从同一个列表删元素，会跳过下一个：删掉 .git 后，.venv 挪到了已经看过的位置。

办法是拼一个新列表，也就是推导式。机器人写 dirnames[:] = [...]，是等推导式拼好之后再整体换掉内容，所以安全。

推导式就是写在一行里的「拼新列表」循环。

小结

  • for item in 列表: 每个元素运行一次，过完自己停。
  • range(a, b) 不包括 b；enumerate 给元素编号。
  • 推导式一行拼出新列表：[x for x in items if ...]。
  • 预算循环：放不下就停，并说明省略了几个。

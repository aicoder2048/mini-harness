是或否

每个判断都从一个是 / 否问题开始。比较两样东西，就得到 True 或 False，这叫布尔值。

运算符问的是例子
== / !=相等吗 / 不相等吗5 == 5 → True
< / >小于 / 大于3 > 10 → False
<= / >=小于等于 / 大于等于20 >= 20 → True

哪一行是在问用户有没有输入 "y"？

  1. answer = "y"
  2. answer == "y"
  3. answer =! "y"
  4. answer != "y"

一个 = 是存值，两个 == 是提问。这是新手最常弄混的地方。

= 是存，== 是问。

if 和 elif

if 条件: 后面缩进 4 格的几行，只在条件为 True 时运行。elif 是「否则如果」，else 是「否则」。Python 从上往下看，只运行第一个成立的分支。

试试把 answer 改成 "a" 或拼错的 "yse"。

这段代码会打印什么？

  1. 超出预算
  2. 有点大了
  3. 先打印「超出预算」，再打印「有点大了」
  4. 没问题

第一个条件已经成立，后面的分支全部跳过。所以顺序很重要。

冒号加缩进；一串 if / elif / else 只走一条路。

真值与假值

if 后面也可以直接放一个值。""、0、None、空列表都算「假」，其余都算「真」。not 把真假反过来。

多了解一点：x is None 和 not x 的区别

0 和 "" 也是假值，但它们是真实存在的值。只想问「有没有值」时，写 x is None：

if not x: 能抓住空字符串、0 和 None。

and、or、in

a and b：两个都真才真。a or b：有一个真就真。x in ("y", "yes")：x 是不是其中之一。

当 answer = "no" 时，if answer == "n" or "no": print("拒绝") 会打印什么？

  1. 什么都不打印
  2. 拒绝
  3. 报 SyntaxError
  4. no

它打印「拒绝」，但只是碰巧对：or "no" 永远是真值，输入 "yes" 也会打印「拒绝」。正确写法是 answer in ("n", "no")。

判断「是不是其中之一」，用 in (...)。

小结

  • 比较得到 True / False；= 存值，== 提问。
  • if / elif / else 只运行第一个成立的分支；冒号和缩进不能少。
  • ""、0、None 是假值；in (...) 判断「是不是其中之一」。
  • 卫语句：先挡坏情况，再干活。

给值起名字

变量就是值的名字，用 = 创建。之后写这个名字（不加引号），Python 就会拿出它的值。

打个比方

变量像贴在值上的名字标签。标签随时可以撕下来，贴到别的值上。

变量 = 名字 + 值。= 的意思是「贴上」，不是数学里的「等于」。

变量会变

机器人用一个计数器记录连续用了几轮工具：从 0 开始，每用完一轮加 1。

这段代码打印什么？

  1. 5
  2. 7
  3. a
  4. NameError

b = a 只是把 b 贴到 a 当时的值 5 上。之后 a 换了值，b 不受影响。

x += 1 就是 x = x + 1：把 x 的值加 1。

值的类型

每个值都有类型。机器人里最常见的是这五种：

类型装什么例子
str 字符串文字，带引号"deepseek-v4-flash"
int 整数整数20
float 浮点数小数0.7
bool 布尔值真 / 假True
None 空值「什么也没有」None

"20"（带引号）是什么类型？

  1. int
  2. float
  3. str
  4. bool

加了引号就是字符串，哪怕里面全是数字。要拿它做算术，先用 int("20") 转换。

给数字起名

变量名可以用字母、数字、下划线，但不能以数字开头、不能有空格，而且区分大小写。习惯写法是小写加下划线：tool_rounds。

全大写的名字是常量：设定一次就不改。机器人把每个重要的数字都写成常量，还注明理由：

编程原则

不写「魔法数字」

代码里光秃秃的 60000 没人知道是什么。给它起个名字，再写一句为什么。

好名字说清楚值的含义；重要的数字写成大写常量。

小结

  • 名字 = 值 创建或修改变量。
  • 带引号的是 str；用 int()、str() 转换类型。
  • // 整除，% 求余，+= 累加。
  • 重要的数字写成大写常量，并注明理由。

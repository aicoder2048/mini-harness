开始之前

你需要准备什么

一个较新的 Chrome、Edge、Firefox 或 Safari。第一次在课里运行 Python 时，页面会从 cdn.jsdelivr.net 下载它（约 15 MB），所以第一次需要联网；之后浏览器会留一份缓存。其他内容都能离线使用。

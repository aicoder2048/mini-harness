给老师和家长 · 教师指南

怎么用这套课带孩子学 Python

15 节课，用 mini-harness 这个真实的 AI coding agent 当教具，从变量讲到类和测试。课文全部是中文，英文术语在第一次出现时附在括号里，关键词表也是中英对照。

设计思路

  • 按概念递进，不按文件顺序。顺序是 变量 → 字符串 → if → while → list → dict/tuple/set → for → 函数 → 异常 → 文件 → 模块 → 类 → 总装 → 测试。每个概念都挑项目里最能说明它的那几行代码来讲，所以同一个文件会在不同课里被反复"拆开"。
  • 主线比喻：拆机（teardown）。agent = 模型（只会"文本进、文本出"的大脑）+ harness（循环、工具、记忆、规则）。每课从机器人身上拆下一个零件。
  • 每课分成 4–7 步，一屏一步。3–5 个知识点各占一步，每步只讲一件事：一两句讲解 + 一段代码（可运行的蓝色代码格，或绿色「拆自机器人」真实代码，与 src/ 原文逐行一致）+ 可能有一道黄色小测验，最后一句「记住」。然后是「动手挑战」（2 道自动判分题，带提示和参考答案）和「小结」（要点 + 中英对照关键词）。页面顶部的「全部展开」可以一页看完整课，方便备课。
  • 每课正文控制在约 1,000 字。次要的展开内容收在默认折叠的「多了解一点」里，学有余力的孩子可以点开看。
  • 代码里哪些是中文、哪些保留英文：注释和给人看的输出用中文；变量名、函数名，以及模仿机器人和 AI 之间通信格式的内容（role、工具名、Error: ...）保持英文，和项目自己的约定一致（发给模型的文字用英文）。
  • 颜色就是机器人终端的 ANSI 颜色：蓝 = You，黄 = 模型，绿 = 工具，红 = 错误，紫 = 请求授权。孩子之后跑真程序时一眼就认得。
  • 只在课里用学过的语法。前面课的练习不会突然出现 def 或 class；摘录里出现后面的概念时，课文会注明"lesson NN 再讲"。

节奏建议

单元课每课时长建议
1 通电00–0425–35 分钟一周 2 课。04 课（while + need_user_input）是全课程的第一个「顿悟点」，值得多花时间。
2 记忆05–0730 分钟左右05 课讲清「模型没有记忆、整个列表每次都重发」，后面一切都建立在这上面。
3 工具08–1030–40 分钟函数和异常是从「写脚本」到「写程序」的分水岭，可以多留些时间做挑战。
4 接线11–1230–40 分钟12 课（类）最抽象，用 FakeProvider / DeepSeekProvider「换大脑」的例子落地。
5 总装13–1440–50 分钟13 课有单步模拟器和浏览器里的迷你 agent，适合一起操作、一起改。

全程大约 8 小时。孩子自学也可以：最后一步底部有「标记本课已学完」，首页会显示进度，每课也会记住学到了第几步（进度只存在这台电脑的浏览器里）。

上课前准备

  1. 用浏览器直接打开 rh-learn-python/index.html（双击即可，不需要服务器）。
  2. 第一次点 Run 时会从 cdn.jsdelivr.net 下载浏览器版 Python（Pyodide 0.27.8，即 CPython 3.12，约 15 MB），之后浏览器有缓存。网络慢的话提前打开任意一课点一次 Run 预热。
  3. 代码格里死循环会在几秒后被自动停止（显示 "Stopped"），不会卡死页面。
  4. 如果想让孩子在手机或别的电脑上用，可以把整个 rh-learn-python/ 目录放到任何静态网站托管上。注意：claude.ai 的 Artifact 页面会拦截 Pyodide 的下载，代码格无法运行，所以不适合发布成 Artifact。

课程里的代码全部在浏览器跑，不花钱。真 agent 要调 DeepSeek API（需要 .env 里的 key，按 token 计费），建议只由老师在关键节点演示：

05 课任意多轮对话灰色 · in 4,210 (cached 3,800) 行：输入 token 随轮数增长，因为整个列表每次重发。

每课要点

00

认识机器人

目标
理解 agent = model + harness；认识 7 个文件；print、注释、从上到下执行。
讨论
"AI 自己能读你的文件吗？"（不能，工具是 harness 执行的）。
卡点
孩子以为 AI 有记忆。先埋下伏笔，05 课揭晓。
01

变量

目标
赋值、五种类型、运算符、类型转换、命名规则、常量、None。
讨论
为什么项目把 20、60_000、30 都写成大写常量还配注释？（no magic numbers）
卡点
= 不是等号；"20" 是字符串。"修三个 bug"挑战要求一次修一个，培养读报错的习惯。
02

字符串与颜色

目标
f-string、转义、ANSI 颜色、字符串方法、切片、input() 返回字符串。
讨论
run_bash 截断长输出时为什么保留结尾？（报错在最后）
卡点
忘写 f；\033[0m 不重置会把后面全染色（正好拿来玩）。
03

做判断

目标
布尔、比较、if/elif/else、真值、and/or/not、in、卫语句（guard clause）。
讨论
ConsoleApprover 为什么把 Ctrl-D 当"拒绝"而不是"允许"？（安全默认值）
卡点
if x == "y" or "yes" 永远为真；缩进。
04

while 循环

目标
while、break、continue、计数器、"刹车"（MAX_TOOL_ROUNDS）、校验循环。
讨论
chatbot 和 agent 在代码上的唯一区别是什么？（need_user_input 这个布尔量）
卡点
死循环：让孩子故意写一个，看页面怎么停下，再找出原因。
05

列表

目标
索引、切片、append/extend、可变性、别名（aliasing）。
讨论
模型服务端是无状态的，"记忆"在哪？每轮成本为什么变高？
卡点
b = a 后改 b 会影响 a；测试里 FakeProvider 用 list(conversation) 拍快照就是为此。
06

字典、元组与集合

目标
消息就是 dict；.get 默认值；元组解包；集合判重。
讨论
为什么每个 tool_call id 都必须有且只有一条 tool 回复？（否则下一次 API 请求被拒）
卡点
KeyError vs .get；{} 是空 dict 不是空 set。
07

for 循环

目标
for、range、enumerate、items、推导式、累加器和"预算"模式。
讨论
为什么给模型看的每个列表都有上限，而且要说明"还有 N 条没列出"？
卡点
range 不含终点；循环中修改正在遍历的列表。
08

函数

目标
def、参数、return、默认值、docstring、类型标注、纯函数、函数是值。
讨论
tools_for_step 为什么好测试？（纯函数：同样的输入永远得到同样的输出，不读文件、不打印）
卡点
print 和 return 分不清；忘记 return 得到 None。
09

错误与异常

目标
读 traceback、try/except、raise、自定义异常、fail fast。
讨论
工具出错时为什么把错误交回给模型，而不是让程序崩溃？什么错误又应该让程序立刻停？
卡点
except: pass 吞掉错误；try 块包太多代码。
10

文件与外部世界

目标
open/with、读写模式、路径、os.walk、环境变量与密钥、subprocess 与人工审批。
讨论
模型在你的电脑上执行命令，哪些防线让这件事可控？（审批、超时、输出上限）
卡点
"w" 模式会清空文件；相对路径取决于启动位置。浏览器里是虚拟磁盘，跑不了 shell 命令。
11

模块与包

目标
import 三种写法、标准库、uv 管理第三方包、自己的模块、__name__、json。
讨论
为什么只有 providers.py 知道 DeepSeek 的格式？换成别家模型要改几个文件？
卡点
把自己的文件起成和标准库模块一样的名字（比如 json.py），结果导入了自己的文件。
12

类与对象

目标
dataclass、实例、方法与 self、继承、property、Protocol 与依赖注入。
讨论
Agent 不关心大脑是 DeepSeek 还是 FakeProvider，只要有 chat() 方法。这像生活里的什么？（USB 接口、充电器）
卡点
忘写 self；类和实例分不清。
13

大循环

目标
完整读懂 Agent.run；在浏览器里搭一个能用工具的迷你 agent 并扩展它。
讨论
模拟器里每一步 conversation 列表怎么变？tool 消息为什么紧跟在带 tool_calls 的 assistant 消息后面？
卡点
代码较长，建议先用模拟器走一遍，再改迷你 agent。
14

测试

目标
assert、pytest、fake、先写测试（red → green）。
讨论
为什么项目的 200 多个测试都不调用真 API？一个"从来没失败过"的测试可信吗？
延伸
毕业项目：给真机器人加一个新工具（例如统计字数），先写测试，再实现，再跑 uv run pytest。

维护与扩展课程

  • 页面结构约定写在 assets/course.js 开头的注释里：.cell（可运行）、.snippet（只读）、figure.excerpt（真实代码，data-file + data-start）、.quiz、.challenge（含 class="check" 判分代码和 class="solution" 参考答案）。
  • 改完课文后运行校验：uv run rh-learn-python/tools/check_lessons.py。它会用同一套运行器在本机 Python 里跑每个代码格，确认参考答案能通过判分、初始代码不能通过，并逐行核对摘录和 src/ 原文是否一致。项目代码改动后跑一次，就能发现哪些摘录的行号过期了。
  • 进度存在浏览器 localStorage（键名 agent-teardown-progress-v1），首页底部可以重置。
